# Escáner PDF 📄

Una herramienta sencilla y eficiente para digitalizar, organizar y convertir tus documentos a formato PDF desde tu dispositivo móvil.

---

## 🚀 Características Principales

* **Digitalización rápida:** Convierte imágenes de tu cámara o galería en documentos PDF.
* **Interfaz intuitiva:** Diseño limpio y fácil de usar.
* **Exportación y guardado:** Genera archivos PDF listos para compartir o almacenar localmente.

---

## 📱 Instalación en el Móvil

### Opción 1: Instalar APK directamente (Android)

1. Ve a la sección de **[Releases / Lanzamientos](https://github.com/fkevinnv/escaner-pdf/releases)** de este repositorio.
2. Descarga la versión más reciente del archivo `.apk`.
3. Abre el archivo en tu teléfono Android.
4. Si tu dispositivo lo solicita, habilita la opción de **"Permitir la instalación desde fuentes desconocidas"** en los ajustes de seguridad.
5. Sigue los pasos en pantalla para completar la instalación y ¡listo!
